Add Loves/Hates traits to Loudmouth personalities so a character's feelings about
places shape its zone banter.

SCHEMA — every personality may define:

    loves = { places = { ... }, entities = { ... } },
    hates = { places = { ... }, entities = { ... } },

Both keys exist in the schema, but only `places` drives behavior in this change.
`entities` is data-only for now (no target detection).

BEHAVIOR — when the player enters a zone or subzone whose name contains a `places`
keyword (case-insensitive substring), the character speaks a line reflecting that
feeling. Precedence: hates > loves > existing zone/subzone lines. A trait match wins
over a generic zone/subzone entry for the same location.

- loves.places = { "Graveyard" }
- hates.places = { "Ironforge" }
