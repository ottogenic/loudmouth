# Session Review — laguna-s-2.1-nvfp4 (2026-07-25, jobs 89–91)

Same big Likes/Hates prompt, same pipeline, same sol architect/review bar as the
qwen3 baseline. Findings are observations only — nothing implemented.

## Result: qwen3 wins this pairing decisively

| Metric | qwen3 (job 88) | laguna (job 91) |
|---|---|---|
| Total wall clock | **51m27s** | **1h47m25s** |
| plan | 1:54 | 2:07 |
| code (first pass) | 10:03 | **47:02** |
| test | 0:34 | 5:00 |
| review + fix loop | 39:00 | 53:16 |
| Review findings | 4 | 4 |
| Malformed replies | 11 | 9 |
| Blocked events | 9 | 5 |

The hypothesis (slower per token, but cleaner code shrinking the fix loop) did not
hold: laguna produced the **same finding count in the same classes** (trait
precedence, missing nil-safety/validation, defensive handling of malformed
containers, test-coverage gap) while paying the full 4× token-speed penalty
everywhere. Findings-per-run being identical suggests sol's bar, not the worker,
determines finding count on this feature; wall clock is then dominated by tk/s.

## Orchestrator DNF (jobs 89–90, before methodology change)

As the loom orchestrator, laguna never called `run` in two attempts. It produced the
single best research request of the night (structured 4-part ask that discovered
Loudmouth has NO existing target-detection code — a fact qwen3's runs never surfaced)
— then ignored two explicit "call run NOW" refusals and exited after relaying
research. Great analyst, non-compliant dispatcher. Runs 3+ used gpt-5.4-mini as
orchestrator (kept for the gpt-oss leg; noted as a methodology asymmetry vs the
qwen3 baseline, whose own orchestration worked fine).

## Harness findings (recommend, don't implement)

1. `omw sync` routes workers by default_models.json prefs, not the live model: swapping
   to an un-preffed model leaves agents pointing at the dead one while the provider
   list moves on → instant server error. Add prefs for laguna/gpt-oss or a
   follow-live mode.
2. Guard refusal messages must state the correct next action per case (pre-build →
   "run NOW", post-build → "relay the report"); implemented tonight for the harness,
   worth keeping.
3. Laguna's orchestrator-instruction non-compliance suggests: if the orchestrator
   model is ever revisited, intake compliance needs its own smoke test.
