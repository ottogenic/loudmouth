## Findings (proposed, NOT implemented)

1. **Code overlay — add a resolution-chain integration rule.** Findings 1–3 (and
   run-8's findings before them) are one class: new dialogue sources broke existing
   resolution order, cooldown keying, or nil-safe fallbacks. Proposed overlay text:
   "When adding a new dialogue source, preserve the existing resolution order and
   cooldown keying; never consume a trigger you cannot satisfy — fall through."
2. **Architect overlay — `.luacheckrc` scope exception.** Finding 4 was not a coder
   error: the plan's scope boundary forbade a file the repo overlay *requires*
   touching when new WoW globals are introduced. Scope boundaries should carry a
   standing exception for `.luacheckrc` additions accompanying new globals.
3. **Contract adherence degrades with session length.** 0 malformed in the 3-minute
   run; 11 in the 51-minute run, concentrated in long resumed fix sessions. Proposal:
   append a one-line contract reminder to resumed-dispatch prompts (cheap tokens,
   targets exactly where drops happen).
4. **Fix-loop economics dominate (76% of the run).** Finding 1 took 4 attempts and two
   forced-BLOCKED cycles in the same increasingly-noisy session. Proposals to evaluate:
   (a) bump the fix session one model rung after the first forced-BLOCKED (ranking
   plumbing already exists); (b) fresh session per fix *attempt*, not just per finding,
   so the coder is not re-reading its own failures.
5. **Pre-build self-ask persists at exactly one** (guard v3 cap working as designed);
   costs ~1–2 min per feature run. Accepted for now; only worth revisiting if the
   orchestrator model changes.
6. **Tooling nit:** the audit script still prints an empty "SKILL-LOAD TELEMETRY"
   section; should print compose + stale-server events instead.
