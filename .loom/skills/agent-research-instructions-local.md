# Loudmouth Research Overlay (agent-research)

## Sources

- Prefer `warcraft.wiki.gg` and `github.com/Gethe/wow-ui-source` (mirrored locally at
  `tools/wow-ui-source/`) for WoW API behavior and templates.
- `wowhead.com` returns **403** to bots; `wowpedia.wiki` is defunct. Do not retry them.
- `addon_examples/` holds other people's published addons -- useful for "how is this
  Classic-Era pattern done in the wild". Read only; it is not our code.
- Repo docs worth reading before searching the web: `docs/PRD.md`,
  `docs/RESEARCH_NOTES.md`, `docs/CHECKLIST.md`.

## Answering

Classic Era is 1.15.x -- confirm any API you cite exists in Classic, not just Retail.
Quote the source (URL or `path:line`) for every claim; separate verified facts from
inference.
